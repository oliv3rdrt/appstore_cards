# Security policy

## Supported versions

Security fixes go into the latest release only.

## Reporting a vulnerability

Please do not open a public issue. Report it privately through [GitHub's private vulnerability reporting](https://github.com/oliv3rdrt/appstore_cards/security/advisories/new) instead.

Please include:

- what an attacker can do, and what they need first, such as an account or a public share link
- the steps to reproduce it, on which Nextcloud and app versions
- any idea you have for a fix

You will get a reply within a week. Once a fix is released, the advisory is published with credit to you, unless you prefer otherwise.

If the problem is in Nextcloud itself rather than in this app, report it to [Nextcloud's bug bounty programme on HackerOne](https://hackerone.com/nextcloud).
